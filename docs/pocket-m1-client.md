# Harness Companion di HP (M1) — catatan fitur

Layar **Settings → Harness Companion (server milikmu)** membuka pairing manual: dua field saja (alamat server + token pairing, spec §5.1 — QR menyusul karena belum ada plugin QR scanner di deps). Setelah `auth.ok`, HP menyimpan *session token* di keychain (`@react-native-keychain`, service `anythingpocket.sessionToken`) — tidak pernah di AsyncStorage atau log — dan setiap reconnect otomatis memakai session token itu dengan exponential backoff 1s→30s (reset saat handshake sukses) plus ping/pong 20s. Chat-nya thin client murni (spec §3.2): prompt dikirim sebagai `turn.request`, balasan di-stream via `turn.delta`, langkah agent tampil ringkas satu baris ("Langkah N — membaca file…"), dan setiap `approval.request` muncul sebagai kartu dengan hitung mundur TTL yang **menolak otomatis** kalau lewat (default REJECT, spec §6). Riwayat chat di-cache read-only di AsyncStorage (`pocket.history`) sehingga tetap terbaca saat server mati; transport M1 adalah `ws://` polos lewat Tailscale/LAN — TLS + cert pinning baru di M3.
