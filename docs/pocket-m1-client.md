# Harness Companion di HP (M1) — catatan fitur

Layar **Settings → Harness Companion (server milikmu)** membuka pairing manual: dua field saja (alamat server + token pairing, spec §5.1 — QR menyusul karena belum ada plugin QR scanner di deps). Setelah `auth.ok`, HP menyimpan *session token* di keychain (`@react-native-keychain`, service `anythingpocket.sessionToken`) — tidak pernah di AsyncStorage atau log — dan setiap reconnect otomatis memakai session token itu dengan exponential backoff 1s→30s (reset saat handshake sukses) plus ping/pong 20s. Chat-nya thin client murni (spec §3.2): prompt dikirim sebagai `turn.request`, balasan di-stream via `turn.delta`, langkah agent tampil ringkas satu baris ("Langkah N — membaca file…"), dan setiap `approval.request` muncul sebagai kartu dengan hitung mundur TTL yang **menolak otomatis** kalau lewat (default REJECT, spec §6). Riwayat chat di-cache read-only di AsyncStorage (`pocket.history`) sehingga tetap terbaca saat server mati; transport M1 adalah `ws://` polos lewat Tailscale/LAN — TLS + cert pinning baru di M3.

## M2b — Trace viewer Detail, Raw/mode belajar, export (spec §7.1)

M2b melengkapi trace viewer ke tiga tingkat. Semua trace event yang dikirim sidecar kini disimpan utuh per turn di `pocketChatStore` (ring buffer maks 200 event terakhir, yang paling tua dibuang) dan ikut ter-cache di `pocket.history`. Tingkat Rangkuman (M2a) tetap; tap satu langkah membuka modal **Detail** yang memasangkan `tool.call.start` dengan `tool.call.end`-nya (tool, argsHash — server memang hanya mengirim hash argumen, bukan args mentah — status ok/fail, durasi ms). Toggle **"Tampilkan event trace mentah (mode belajar)"** di bagian Detail teknis chat (`pocket.settings.raw_mode`, AsyncStorage `pocket.rawMode`, default OFF) menambahkan tombol **JSON mentah** di modal: event persis seperti diterima, pretty-print 2 spasi. Setiap turn yang punya trace bisa di-**export/share satu file** dari panel Rangkuman: Markdown (teks percakapan + tabel langkah) atau JSON (raw events), ditulis ke Downloads/Documents via `writeToDeviceDownloads` lalu dibagikan dengan `react-native-share` — tanpa dependency baru. Sebelum export, semua key payload yang mirip secret (token/password/api key/cookie/kartu) di-strip ulang di sisi klien (`redactSecrets`), lapis kedua di atas sanitasi server; session token pairing tidak pernah masuk event trace.
