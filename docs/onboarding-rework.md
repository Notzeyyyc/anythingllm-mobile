# Onboarding rework (UX de-jargonisasi, spec §7.9)

Alur onboarding AnythingPocket diringkas jadi dua langkah: **Welcome** (+ blok kredit fork GPLv3, link ke repo upstream) → **ModeSelection** ("Mau pakai gimana?", copy outcome-oriented bilingual EN+ID) dengan dua kartu: *Pakai server sendiri* (masuk ke screen Pocket existing untuk pairing; saat `auth.ok` status jadi `connected`, `completeOnboarding()` menandai selesai) atau *On-device saja* (ModelSelection upstream; selesai langsung tandai onboarding selesai), plus opsi *Lewati* yang menandai selesai dengan default on-device (pairing tetap bisa dari Settings). Layar **DataHandling** dan **Survey** dihapus dari alur dan dari repo — copy "anonymous data collection" tidak ada lagi karena collector memang sudah no-op. Workspace default yang dulu dibuat DataHandling kini dibuat `completeOnboarding()` di `src/hooks/useOnboardingHook.ts`; flag storage `onboarding_data_handling_completed` dipertahankan sebagai penanda final supaya semua pembaca lama (useInitialRoute, AssistantApp, QuickContextApp, DeepLinks, SharedContent, HighlightsHost) tidak perlu migrasi. Putusan rute launch dipisah jadi helper murni `nextOnboardingRoute()` (unit-tested di `src/hooks/__tests__/onboardingRoute.test.ts`).
