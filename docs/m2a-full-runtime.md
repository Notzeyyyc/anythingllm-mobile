# M2a — Mode Full (Pi host-process di balik `HarnessRuntime`)

**Arsitektur (1 paragraf):** Mode Lengkap jalan sebagai Pi host-process (`@ai-sdk/harness@1.0.164` + `@ai-sdk/harness-pi@1.0.167` + `@ai-sdk/sandbox-just-bash@1.0.164` + `just-bash@2.14.5`, semua di-pin per spike GO) di balik abstraksi `HarnessRuntime` (`src/full/HarnessRuntime.ts`) — kontrak `runTurn(prompt, opts) → result`, event stream via SATU trace schema (`route.decided` ditambah ke whitelist `schema.ts`), approval hook Promise-based dengan kontrak identik Lite, dan `interrupt(turnId)` via AbortSignal. `PiRuntime` (`src/full/pi-runtime.ts`) memetakan lifecycle callbacks Pi (`onLanguageModelCallStart/End`, `onToolExecutionStart/End`) ke event `llm.call.*`/`tool.call.*`, menjalankan Pi di `@ai-sdk/sandbox-just-bash` `OverlayFs` ber-root di workspace (baca disk nyata, tulis in-memory, tidak bisa keluar root), dan menyediakan host tools `read_file`/`list_dir`/`write_file` — `write_file` wajib approval (diff + TTL hard default REJECT). Router deterministik (`src/router.ts`, tanpa LLM) memilih Lite/Full: pin user (`POCKET_FORCE_RUNTIME`) > cue tool/file > chat pendek → Lite, ambigu → Full (fail toward capability); keputusan tercatat sebagai `route.decided {runtime, reason}` di trace. Secrets proxy (`src/secrets-proxy.ts`) HTTP 127.0.0.1 port acak menyimpan API key di proses parent dan inject `Authorization` ke upstream — PiRuntime hanya melihat `POCKET_PROXY_URL` + placeholder key; history sesi di-serialize minimal ke SQLite (`session_history`). Interrupt mid-run: pesan WS baru `{"type":"turn.interrupt","turnId"}` (WS protocol v1.1, tambahan non-breaking; Lite juga mendukung via `abortSignal` di `streamText`) → `turn.interrupt.ack` + `turn.end ok:false reason "interrupted"`.

**Keterbatasan:**
- **Secrets proxy bukan isolasi proses penuh** — runtime Pi host-process di mesin yang sama; proxy mencegah key bocor via env/config/log child, bukan membatasi akses memori/network proses. Isolasi penuh = kerja sandbox (item di bawah).
- **Approval gate mencakup host tools kita (`write_file`) DAN Pi builtins** — `permissionMode: 'allow-reads'` (read auto; write/edit/bash minta approval) dengan `HarnessAgentPendingToolApproval` dijawab via approval hook yang sama dengan Lite: PiRuntime men-stream `tool-approval-request` part, memanggil `approvalHandler`, lalu melanjutkan turn via `agent.continueStream({toolApprovalContinuations})`. Ditutup 26 Okt 2026 (lihat status sandbox di bawah).
- `tool()` host tools dibangun sebagai plain objects + cast (harness bundle ai@7 types vs ai@5 di sidecar); dokumentasikan kalau mau unifikasi versi `ai`.

**Status sandbox bash: IMPLEMENTED (26 Okt 2026 — syarat rilis spec §6 tertutup).**
- **Mekanisme: bubblewrap (bwrap 0.6.1)** — dipilih karena docker tidak terpasang di host, Landlock network control tidak tersedia di kernel 5.15 (FS Landlock saja tidak menutup egress), dan bwrap unprivileged user-namespace cukup untuk semua syarat. `src/sandbox.ts`: deteksi `detectMechanism()` (bwrap > docker > none) + `resolveSandbox(POCKET_SANDBOX)` + `createSandboxSession()` yang membungkus `HarnessV1NetworkSandboxSession` just-bash (file I/O tetap OverlayFs workspace) dengan override `run`/`spawn` → proses bash NYATA di dalam bwrap.
- **Flags:** `--unshare-net --unshare-pid --unshare-ipc --die-with-parent --new-session --clearenv --ro-bind / /` + workspace re-bind RW (juga di-alias ke `/home/user` — HarnessAgent membuat work dir per-sesi di sana), `--tmpfs /tmp /run /home`, `--proc --dev`, `/etc/passwd` + `/etc/shadow` di-mask `/dev/null`.
- **Egress allowlist:** sandbox TANPA network sama sekali (`--unshare-net`) — satu-satunya jalan keluar adalah **secrets-proxy UNIX socket** yang di-bind-mount read-only (`startSecretsProxy({socketPath})`, proxy sekarang listen TCP loopback untuk parent + UNIX socket untuk sandbox). Trade-off yang dipilih (paling simpel): Pi LLM calls tetap parent-side TCP loopback (provider config Pi tidak punya hook custom fetch); dari dalam sandbox proxy diakses via `curl --unix-socket <path> <url>` — diverifikasi 200 + `Authorization` di-inject upstream (test b).
- **Fallback policy (fail toward SAFETY — sengaja beda dari routing yang fail toward capability):** `POCKET_SANDBOX=required` tanpa mekanisme → error jelas, turn gagal; `auto`/`none` tanpa mekanisme → warning keras di trace (`sandbox.decided {mechanism:'none', bashEnabled:false, reason}`) dan tool bash Pi di-FILTER keluar (`builtinToolFiltering deny bash`) — bash tidak pernah jalan tanpa sandbox. Keputusan sandbox tercatat sebagai event `sandbox.decided` di schema trace tunggal.
- **Sisa gap:** (1) Landlock network kontrol tidak dipakai karena kernel 5.15 tidak punya — netns-none menggantikannya penuh; (2) `abortSignal` belum membunuh child bwrap (dibatasi `--die-with-parent`); (3) tulisan Pi file builtins masuk OverlayFs in-memory, sedangkan bash nyata menulis disk workspace — dua view berbeda untuk sesi yang sama (bash melihat disk; file tools melihat overlay+baca disk), tidak menghalangi keamanan tapi bisa membingungkan model; upgrade path = file tools ke sandbox session yang sama.
